Real-object silhouettes for a virtual human

Camera frames are segmented, each object becomes an equal-distance silhouette mesh on the calibrated floor, and the meshes are drawn depth-only so they hide the avatar wherever the real object is nearer. Meshes keep their ids across updates, so a moving object can be followed. Tap an object or use the centre ray (gaze), or say/type its class.
